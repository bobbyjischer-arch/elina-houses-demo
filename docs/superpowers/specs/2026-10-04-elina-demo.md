# Elina houses demo
Personalized public, non-official concept for Elina Chichkova / Region-Partner. User explicitly authorized a new public repo, free live demo and autonomous decisions, waiving intermediate spec/plan sign-off. No contact with lead.

## Scope
Russian editorial home, three-source project catalog, detail galleries/plans, compare, saved projects, about, local-only request wizard, source transparency. No stale prices, fabricated availability, promised return, client case claims or testimonials. Source descriptions are archived project descriptions, not current offers. Actual photographs and architectural visualizations are labelled separately. Copyright remains with authors; remove on request.

## Design
Audience: buyers exploring a house in Sochi, not developers. Design read: quiet architectural journal, dark graphite, cool paper, restrained forest accent, oversized Cyrillic typography and landscape photography. DESIGN_VARIANCE 7, MOTION_INTENSITY 2, VISUAL_DENSITY 4. Motion is subordinate to selection, respects reduced motion. Token families: graphite #182822, paper #f5f6f3, muted #66716b, green #38654f; 8px soft controls, no rounded SaaS-card wallpaper. 390px and 1440px responsive.

## Boundaries
Not official, noindex/nofollow. Demo form has no data transport, no personal data saved. Only project IDs persist locally. Contact links explicitly external and voluntary. Public sources separate prices/status caveats. All existing repos untouched.

## Acceptance
Filters reflect real construction type. Compare/saved persist safely, unknown IDs ignored. Detail gallery opens with keyboard and closes restoring focus. Wizard requires goal, name, valid contact and consent; final screen states nothing sent. No uncaught console errors, missing images or horizontal overflow. Test desktop/mobile, reload state, malformed storage, back/forward routing, form boundaries. Public deployment fetched and rendered before hand-off. No guarantee of sale.
