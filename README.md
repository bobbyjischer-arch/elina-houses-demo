# Регион-Партнер · демонстрационный сайт

Неофициальный персонализированный концепт для Элины Чичковой от Fernandness. Полноценная **клиентская демоверсия**, не официальный сайт и не готовая система продаж.

## Возможности
- Главная и каталог трёх проектов: Four Houses, MiniBarn, Living Houses.
- Фильтры по конструкции; страницы с фотографиями, характеристиками и схемами.
- Галерея с клавиатурным управлением и различением фото/визуализаций.
- Сравнение и избранное. Сохраняются только ID проектов в localStorage.
- Трёхшаговая демонстрационная форма с валидацией. **Ничего не отправляет, имя и контакты не сохраняет.**
- Мобильная версия, reduced motion, фокус клавиатуры, noindex/nofollow.
- Раздел об источниках, актуальности данных и правах на изображения.

## Факты и ограничения
Только открытые материалы компании. Старые цены, ипотечные ставки, доходность, отзывы и выдуманные показатели не использованы. Наличие и состояние объектов не подтверждены. Площадь MiniBarn не вычислялась из габаритов, площадь Living Houses не выдумывалась.

Публичный доступ к изображению не означает разрешения на коммерческое использование. Права остаются у авторов. Перед официальным запуском нужны согласование правообладателей, обновление данных, реквизиты и документы компании, законное подключение формы и согласование обработки персональных данных. Нет админ-панели, CRM, backend, оплаты, действующей отправки или Telegram Mini App.

## Запуск
Никакой сборки или платных сервисов:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Просто открыть исходный index.html как файл нельзя: изображения загружаются из локальных JSON. Отдельный автономный HTML в архиве работает без сервера.

## Проверка

```sh
npm test
npm install
# В другой консоли запустите сервер на 4173.
npm run test:browser
```

Для браузерных тестов нужен Chromium в PATH. Альтернатива: переменная CHROME_BIN с путём к бинарнику. Тесты проверяют выбор, сохранение, восстановление после испорченного localStorage, приватность формы, сохранность черновика при изменениях в другой вкладке и ширину 390px.

Авторская проверка, без независимого ревьюера. Автоматический axe WCAG AA аудит основных маршрутов проведён на 1440px и 390px; отдельно осмотрены снимки. Автоматические тесты не заменяют полноценный ручной аудит.

## Бесплатная публикация
GitHub Pages: Settings → Pages → Source → GitHub Actions. После включения запустите `Publish static demo` из вкладки Actions. Workflow публикует только статические файлы и выполняет unit-тесты. Настройки Pages требуют административных прав, которых может не быть у MCP-подключения.

Для временного показа также подходит raw.githack.com со ссылкой на конкретный публичный коммит. Этот сторонний бесплатный сервис может сначала показать подтверждение перехода, не гарантирует доступность и не заменяет производственный хостинг.
